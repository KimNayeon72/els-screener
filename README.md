# ELS 주간 자동 스크리닝

키움증권/NH투자증권이 판매중인 ELS 중 기초자산 2개 구성, 연 수익률 15% 이상,
최근 2년간 기초자산이 첫 조기상환 기준가 이하로 내려간 적 없는 상품을
매주 월요일 자동으로 찾아 엑셀로 정리하는 스크립트입니다.
이메일은 보내지 않고, GitHub Actions의 결과물(Artifact)로 엑셀을 남겨두면
매주 직접 다운로드하는 방식입니다.

## 왜 키움/NH 사이트를 직접 긁지 않았나
- NH투자증권 사이트는 robots.txt로 자동 접근을 명시적으로 차단하고 있어 직접 스크래핑하지 않았습니다.
- 키움증권 사이트는 실제 수익률 데이터가 자바스크립트로 화면에 채워지는 구조라 단순 요청으로는 가져올 수 없습니다.
- 대신 한국거래소(KRX)가 운영하는 **파생결합증권 통합정보플랫폼**(공식 공개 데이터, 로그인 불필요, robots 차단 없음)에서
  판매사가 키움증권/NH투자증권인 상품만 걸러서 가져옵니다.

## 처음 한 번만 해야 하는 설정

### 1) KRX 'bld' 값 확인
1. 크롬으로 https://tip.krx.co.kr/TIP010100.cmd 접속
2. F12(개발자도구) → Network 탭 → XHR 필터 체크
3. 화면에서 "조회" 버튼 클릭
4. `getJsonData.cmd` 요청을 클릭 → Payload(또는 Form Data) 탭에서 `bld` 값 복사
5. 이 값을 GitHub Secrets의 `KRX_BLD`에 저장 (아래 4번 항목 참고)

### 2) 응답 필드명 확인 (최초 1회)
`python main.py`를 로컬에서 한 번 실행해보면 `output/krx_raw_sample.json`에 원본 응답이 저장됩니다.
`krx_client.py`의 `_parse_row()` 함수 안 필드명(`ISU_NM`, `BAS_IDX_NM` 등)이 실제 응답과 다르면
이 파일을 열어보고 맞는 키 이름으로 고쳐주세요.

### 3) 기초자산 티커 매핑 채우기 (2026-09-17 기준 31개 등록 완료, 계속 관리 필요)
`config.py`의 `ASSET_TICKER_MAP`에 2026-09-17 시점 키움/NH 상품에 등장한 기초자산은
모두 등록해뒀습니다. 다만 매주 새 상품이 계속 올라오므로, 새로운 기초자산이 나올
때마다 매핑을 추가해야 정확한 배리어 판정이 됩니다. 매핑에 없는 기초자산은
엑셀에 "판정불가"로 표시되고 자동으로 추천 대상에서 제외됩니다.

**가장 쉬운 방법**: 매주 도착하는 엑셀에서 "판정불가"로 표시된 행의 기초자산1/2 열을
확인한 다음, 그 이름 목록을 그대로 Claude에게 붙여넣고 "이 기초자산들 티커 매핑 추가해줘"
라고 요청하면 됩니다. Claude가 야후파이낸스에서 티커를 찾아 config.py를 직접 고쳐줄 수 있습니다.
(직접 하고 싶다면: finance.yahoo.com에서 종목명으로 검색 → 상단에 나오는 코드를 그대로 사용)

### 4) 결과 다운로드 방법 (매주)
1. 이 GitHub 저장소 → Settings → Secrets and variables → Actions → New repository secret 에서
   `KRX_BLD` 하나만 등록하면 됩니다 (값은 1번에서 확인한 값).
2. 매주 월요일 자동 실행이 끝나면, 저장소 → **Actions** 탭 → `Weekly ELS Screener` →
   해당 실행(run) 클릭 → 맨 아래 **Artifacts** 항목의 `els-report`를 클릭하면 zip으로
   다운로드됩니다. 압축을 풀면 그 주의 엑셀 파일이 들어있습니다. (90일간 보관됩니다)

## 로컬 테스트
```bash
pip install -r requirements.txt
export KRX_BLD="..."
python main.py
```
실행하면 `output/` 폴더에 그 주의 엑셀 파일이 바로 생성됩니다.

## 자동 실행
GitHub 저장소에 push하면 `.github/workflows/els_screener.yml`이 매주 월요일 09:00(KST)에
자동으로 실행됩니다. `Actions` 탭에서 `Run workflow`를 눌러 즉시 테스트할 수도 있습니다.

## 한계와 주의사항 (반드시 읽어주세요)
- 이 스크립트는 **1차 스크리닝 도구**입니다. 배리어 판정은 기초자산의 발행일 종가를 최초기준가로
  근사한 값이라, 실제 발행사 고시 기준가와 소폭 차이가 날 수 있습니다.
- 개별 해외 종목형 ELS는 `ASSET_TICKER_MAP`에 티커를 미리 등록해두지 않으면 자동으로 걸러지지 않고
  "판정불가"로 표시되니, 엑셀에서 이 상품들을 별도로 확인해주세요.
- 최종 매수 전에는 반드시 상품설명서(투자설명서/KID)와 발행사 신용등급을 직접 확인하시기 바랍니다.
